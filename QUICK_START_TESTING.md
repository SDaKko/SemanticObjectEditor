# Быстрый старт тестирования

## Самый простой способ протестировать программу

### Вариант 1: Автоматические тесты (рекомендуется)

```bash
# Запустите все тесты одной командой:
python run_tests.py
```

Этот скрипт запустит:
- ✅ Unit-тесты функции `build_regex`
- ✅ Интеграционные тесты полного рабочего процесса

### Вариант 2: Отдельные тесты

```bash
# Только unit-тесты:
python test_regex.py

# Только интеграционные тесты:
python test_integration.py
```

### Вариант 3: Ручное тестирование через GUI

```bash
# Запустите программу:
python gui_start.py
```

**Инструкция:**
1. Меню → **Редактор семантических объектов** → **Создание объекта** → **Добавить текстовый поток**
2. Добавьте несколько текстовых потоков (например, 2-3)
3. В поле **Характеристики** введите:
   ```
   Q1: начало работы
   Q2: основной процесс
   Q3: завершение работы
   ```
4. Нажмите **Сохранить характеристики**
5. Нажмите **Начать генерацию**
6. Проверьте результат в поле **Регулярное выражение**

### Вариант 4: Быстрый тест функции build_regex

Создайте файл `quick_test.py`:

```python
from regex import build_regex

# Простой тест
transitions = {
    'S0': {'a': 'S1'},
    'S1': {'b': 'Z'},
    'Z': {}
}

result = build_regex('S0', transitions)
print(f"Результат: {result}")
```

Запустите:
```bash
python quick_test.py
```

## Что проверить после тестирования:

✅ Регулярное выражение генерируется  
✅ Используется стандартный синтаксис (|, *, скобки)  
✅ Нет ошибок при выполнении  
✅ Результат соответствует структуре графа переходов
