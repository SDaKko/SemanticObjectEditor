# 📊 Функция разделения характеристик по метрикам графа

## Описание

Добавлена возможность автоматического разделения характеристик семантического объекта по метрикам на основе количества дуг и вершин графа с градацией сложности.

## Функциональность

### 1. Вычисление метрик графа

Система автоматически вычисляет следующие метрики:

- **Вершины (характеристики)**: Количество уникальных характеристик в графе
- **Дуги (переходы)**: Общее количество переходов между характеристиками
- **Плотность графа**: Отношение количества дуг к максимально возможному количеству
- **Оценка сложности**: Комплексная метрика от 0.0 до 1.0, учитывающая все параметры

### 2. Разделение характеристик по категориям

Характеристики автоматически разделяются на категории на основе:

- **Глобальной сложности графа**: Общая оценка сложности всего графа
- **Локальной сложности характеристики**: Количество исходящих дуг и их плотность

### 3. Типы градации

Доступны два типа градации:

#### Простая градация (0.5, 0.75, 1.0)
- **0.5**: Низкая сложность
- **0.75**: Средняя сложность  
- **1.0**: Высокая сложность

#### Детальная градация (0.5, 0.6, 0.7, 0.8, 0.9, 1.0)
- Более точное разделение на 6 категорий
- Позволяет лучше анализировать сложность характеристик

## Интерфейс

### Новые элементы интерфейса:

1. **Поле "Метрики графа"**:
   - Отображает основные метрики графа
   - Вершины, дуги, плотность, оценка сложности

2. **Поле "Категории характеристик по метрикам"**:
   - Показывает разделение характеристик по категориям
   - Для каждой категории отображается:
     - Порог сложности
     - Количество характеристик
     - Список характеристик
     - Детали для каждой характеристики (количество исходящих дуг, локальная сложность)

3. **Выбор типа градации**:
   - Радиокнопки для выбора между простой и детальной градацией
   - Выбор применяется при следующей генерации

## Использование

### Шаг 1: Выбор типа градации
1. Выберите тип градации перед генерацией:
   - **Простая (0.5, 0.75, 1.0)** - для быстрого анализа
   - **Детальная (0.5-1.0)** - для детального анализа

### Шаг 2: Генерация
1. Добавьте характеристики и текстовые потоки
2. Нажмите кнопку **"Генерация"**
3. Система автоматически:
   - Вычислит метрики графа
   - Разделит характеристики по категориям
   - Отобразит результаты в соответствующих полях

### Шаг 3: Анализ результатов

**Метрики графа:**
```
Вершины (характеристики): 5
Дуги (переходы): 12
Плотность графа: 0.600
Оценка сложности: 0.750
```

**Категории характеристик:**
```
Категория 0.50 (сложность ≤ 0.50):
  Количество характеристик: 2
  Характеристики: Q1, Q5
    - Q1: исходящих дуг=1, локальная сложность=0.450
    - Q5: исходящих дуг=0, локальная сложность=0.300

Категория 0.75 (сложность ≤ 0.75):
  Количество характеристик: 2
  Характеристики: Q2, Q3
    - Q2: исходящих дуг=3, локальная сложность=0.650
    - Q3: исходящих дуг=2, локальная сложность=0.600
```

## Алгоритм вычисления

### Метрики графа:

1. **Вершины**: Количество уникальных ключей в словаре характеристик
2. **Дуги**: Сумма длин всех списков следующих характеристик
3. **Плотность**: `edges / (vertices * (vertices - 1))`
4. **Оценка сложности**: Взвешенная комбинация:
   - 30% - нормализованное количество вершин
   - 40% - нормализованное количество дуг
   - 30% - плотность графа

### Локальная сложность характеристики:

1. **Исходящие дуги**: Количество переходов из характеристики
2. **Локальная плотность**: `исходящие_дуги / (общее_количество_характеристик - 1)`
3. **Локальная сложность**: `глобальная_сложность * 0.6 + локальная_плотность * 0.4`

### Категоризация:

Характеристика относится к категории, если её локальная сложность не превышает порог категории.

**Характеристики:**
- Q1-Q10: множество характеристик с множественными переходами

**Результат:**
- Вершины: 10
- Дуги: 20+
- Оценка сложности: 0.7-1.0
- Характеристики распределены по всем категориям

## Преимущества

1. **Автоматический анализ**: Не требует ручного анализа структуры

4. **Информативность**: Детальная информация о каждой характеристике
