# 🔧 Исправление ошибки RecursionError

## Проблема
При наличии циклов в графе (например, `q2 -> q2`) возникала бесконечная рекурсия в функции `process_edge` в файле `build_dictionary.py`.

## Ошибка
```
RecursionError: maximum recursion depth exceeded
```

## Причина
Функция `process_edge` не проверяла наличие циклов и вызывала сама себя бесконечно при обработке циклических переходов.

## Решение

### 1. Добавлена защита от бесконечной рекурсии
- Максимальная глубина рекурсии: `MAX_RECURSION_DEPTH = 100`
- При достижении максимальной глубины создается переход к финальному состоянию

### 2. Добавлено отслеживание циклов
- Используется множество `visited_edges` для отслеживания обработанных ребер в текущем пути
- При обнаружении цикла создается самопетля (переход из состояния в само себя)

### 3. Улучшена обработка самопетель
- Когда ребро уже обрабатывается в текущем пути, создается самопетля
- Если это последний элемент, создается переход к финальному состоянию

## Изменения в коде

### Файл: `dictionary_of_transitions/build_dictionary.py`

**До:**
```python
def process_edge(edge, current_state):
    # ... код без проверки циклов
    process_edge(next_edge, new_state)  # Бесконечная рекурсия при циклах
```

**После:**
```python
def process_edge(edge, current_state, visited_edges=None, depth=0):
    # Проверка максимальной глубины
    if depth > MAX_RECURSION_DEPTH:
        # Создаем переход к финальному состоянию
        return
    
    # Проверка циклов
    if edge in visited_edges:
        # Создаем самопетлю
        transitions[current_state][edge] = current_state
        return
    
    # ... остальной код с отслеживанием visited_edges и depth
```

## Как проверить исправление

1. **Используйте тестовые данные с циклами:**
   ```
   Характеристики:
   Q1: начало работы
   Q2: основной процесс
   Q3: завершение работы
   
   ТП 1:
   Начало работы. Основной процесс. Основной процесс. Завершение работы.
   ```

2. **Проверьте консоль:**
   - Должны появиться сообщения об обнаружении циклов (если есть)
   - Не должно быть ошибки `RecursionError`

3. **Проверьте результат:**
   - Регулярное выражение должно быть сгенерировано
   - Самопетли должны быть представлены как циклы в регулярном выражении

## Примеры циклов

### Цикл в середине пути:
- Граф: `q1 -> q2 -> q2 -> q3`
- Ожидаемый результат: Регулярное выражение с циклом `(q1(q2)*q3)`

### Самопетля:
- Граф: `q2 -> q2`
- Ожидаемый результат: Регулярное выражение с циклом `(q2)*`

3. **Корректность:** Правильная обработка самопетель и циклов
