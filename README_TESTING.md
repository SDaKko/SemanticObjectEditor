## 🧪 Типы тестов

### 1. Unit-тесты (`test_regex.py`)

Проверяют функцию `build_regex` на различных случаях:

- ✅ Простые линейные пути
- ✅ Множественные переходы
- ✅ Самопетли (переходы в себя)
- ✅ Несколько меток в одно состояние
- ✅ Пустые состояния
- ✅ Сложные структуры
- ✅ Обнаружение циклов

**Запуск:**
```bash
python test_regex.py
```

### 2. Интеграционные тесты (`test_integration.py`)

Проверяют полный рабочий процесс:

- ✅ Извлечение скриптов из текстов
- ✅ Построение графа переходов
- ✅ Генерацию регулярного выражения

**Запуск:**
```bash
python test_integration.py
```

### 3. Быстрый тест (`quick_test.py`)

Простой тест для быстрой проверки:

**Запуск:**
```bash
python quick_test.py
```

## 🎯 Сценарии тестирования

### Сценарий 1: Автоматическое тестирование

```bash
# Запустите все тесты
python run_tests.py

# Или по отдельности
python test_regex.py
python test_integration.py
```

### Сценарий 2: Ручное тестирование через GUI

1. Запустите программу:
   ```bash
   python gui_start.py
   ```

2. Создайте новый объект:
   - Меню → **Редактор семантических объектов** → **Создание объекта** → **Добавить текстовый поток**

3. Добавьте характеристики:
   ```
   Q1: начало работы
   Q2: основной процесс
   Q3: завершение работы
   ```

4. Добавьте текстовые потоки:
   ```
   TP1: Начало работы. Основной процесс. Завершение работы.
   TP2: Начало работы. Основной процесс. Основной процесс. Завершение работы.
   ```

5. Нажмите **Начать генерацию**

6. Проверьте результат в поле **Регулярное выражение**

### Сценарий 3: Тестирование конкретной функции

```python
from regex import build_regex

# Ваш тест
transitions = {
    'S0': {'a': 'S1'},
    'S1': {'b': 'Z'},
    'Z': {}
}

result = build_regex('S0', transitions)
print(result)
```

## 🐛 Отладка

### Если тесты не проходят:

1. **Проверьте зависимости:**
   ```bash
   pip list | grep -E "networkx|matplotlib|Pillow"
   ```

2. **Проверьте структуру данных:**
   - Убедитесь, что словарь переходов корректен
   - Проверьте наличие начального состояния 'S0'

3. **Включите подробный вывод:**
   - Функция `build_regex` уже выводит отладочную информацию

4. **Проверьте логи:**
   - Все print-выводы показывают процесс работы
