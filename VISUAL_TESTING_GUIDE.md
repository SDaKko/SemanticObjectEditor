# 🖼️ Визуальное руководство по тестированию

## 📸 Как должны выглядеть данные в интерфейсе

---

## ШАГ 1: Ввод характеристик

### Поле "Характеристики" должно выглядеть так:

```
┌─────────────────────────────────────────────────────┐
│ Характеристики                                      │
├─────────────────────────────────────────────────────┤
│ Q1: начало работы                                   │
│ Q2: основной процесс                                │
│ Q3: завершение работы                               │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**Точный текст для копирования:**
```
Q1: начало работы
Q2: основной процесс
Q3: завершение работы
```

**После нажатия "Сохранить характеристики"** в консоли должно появиться:
```
Сохранено: {'Q1': 'начало работы', 'Q2': 'основной процесс', 'Q3': 'завершение работы'}
```

---

## ШАГ 2: Добавление текстовых потоков

### После добавления ТП 1, поле должно выглядеть так:

```
┌─────────────────────────────────────────────────────┐
│ ТФ 1                                                │
├─────────────────────────────────────────────────────┤
│ Начало работы. Основной процесс. Завершение работы.│
│                                                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### После добавления ТП 2:

```
┌─────────────────────────────────────────────────────┐
│ ТФ 1                                                │
├─────────────────────────────────────────────────────┤
│ Начало работы. Основной процесс. Завершение работы.│
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ ТФ 2                                                │
├─────────────────────────────────────────────────────┤
│ Начало работы. Основной процесс. Основной процесс. │
│ Завершение работы.                                  │
└─────────────────────────────────────────────────────┘
```

## 📋 ПОЛНЫЙ ПРИМЕР: Что должно быть на экране

### Левая панель (Текстовые потоки):

```
┌─────────────────────────────────────────────────────┐
│ [Загрузить ТФ 1]  [Удалить]                         │
├─────────────────────────────────────────────────────┤
│ Начало работы. Основной процесс. Завершение работы.│
│                                                     │
│ [Регулярное выражение для ТФ 1]                     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ [Загрузить ТФ 2]  [Удалить]                         │
├─────────────────────────────────────────────────────┤
│ Начало работы. Основной процесс. Основной процесс. │
│ Завершение работы.                                  │
│                                                     │
│ [Регулярное выражение для ТФ 2]                     │
└─────────────────────────────────────────────────────┘
```

### Правая панель (Характеристики и результаты):

```
┌─────────────────────────────────────────────────────┐
│ Характеристики                                      │
├─────────────────────────────────────────────────────┤
│ Q1: начало работы                                   │
│ Q2: основной процесс                                │
│ Q3: завершение работы                               │
│                                                     │
│ [Сохранить характеристики]                           │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ Имя объекта                                         │
├─────────────────────────────────────────────────────┤
│ Тестовый объект                                     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ Регулярное выражение                                │
├─────────────────────────────────────────────────────┤
│ (Q1(Q2)*Q3)                                         │
│                                                     │
└─────────────────────────────────────────────────────┘

[Начать генерацию]  [Сохранить объект]
```

---

## ✅ Чек-лист перед запуском генерации:

- [ ] Характеристики введены в формате `Q1: текст`
- [ ] Нажата кнопка "Сохранить характеристики"
- [ ] В консоли появилось сообщение "Сохранено: {...}"
- [ ] Добавлен хотя бы один текстовый поток
- [ ] В текстовом потоке есть текст (не пустое поле)
- [ ] Слова в текстовых потоках совпадают со словами в характеристиках
- [ ] Кнопка "Начать генерацию" активна

---

## 🎯 Примеры правильного и неправильного ввода

### ✅ ПРАВИЛЬНО - Характеристики:

```
Q1: начало работы
Q2: основной процесс
Q3: завершение работы
```

### ❌ НЕПРАВИЛЬНО - Характеристики:

```
Q1 начало работы          ← Нет двоеточия
Q1-начало работы          ← Неправильный разделитель
Q1:начало работы          ← Нет пробела после двоеточия (работает, но некрасиво)
```

### ✅ ПРАВИЛЬНО - Текстовый поток:

```
Начало работы. Основной процесс. Завершение работы.
```

### ❌ НЕПРАВИЛЬНО - Текстовый поток:

```
Старт процесса. Главный этап. Финал.  ← Слова не совпадают
Начало работы Основной процесс         ← Нет точек между предложениями
                                            (может работать, но не рекомендуется)
```

## 📊 Ожидаемый результат генерации

### В консоли вы увидите:

```
Последовательность хар-к ТФ 1:  ['Q1', 'Q2', 'Q3']
Последовательность хар-к ТФ 2:  ['Q1', 'Q2', 'Q2', 'Q3']
Первыми ребрами могут быть ['Q1']
Последними ребрами могут быть ['Q3']
Словарь хар-к объекта:  {'Q1': ['Q2'], 'Q2': ['Q2', 'Q3']}
...
Регулярное выражение (Q1(Q2)*Q3)
```

### В поле "Регулярное выражение":

```
(Q1(Q2)*Q3)
```

или похожее выражение, отражающее структуру переходов.

---

## 🔍 Как проверить, что всё работает правильно:

1. **Проверьте консоль**: Должны быть сообщения о последовательностях
2. **Проверьте поле "Регулярное выражение"**: Должно быть непустым
3. **Проверьте скрипты**: В консоли должны быть выведены последовательности для каждого ТП
4. **Проверьте граф**: Должен быть создан файл `graph.png` с визуализацией

---

## 💡 Советы:

1. **Начните с простого**: Используйте Пример 1 (3 характеристики)
2. **Проверяйте совпадение**: Слова должны совпадать точно
3. **Используйте точки**: Разделяйте предложения точками
4. **Одна характеристика на строку**: В поле характеристик
